# PCA Launch Control

## Project Brief
To build a streamlined, high-performance web platform for the Porsche Club of America Rocky Mountain Region (PCA RMR). The MVP focuses strictly on Autocross (AX) and track events by unifying member authentication via MotorsportReg, automating 2026 event scoring using direct VisualAX SQLite database ingestion, and centralizing community-driven media links.
